## Operator path for real labels

1. Evaluation lead selects approved, deidentified, held-out evidence and records task, pinned model, segment and predictions in a restricted JSON dataset. Prediction cases contain opaque id, segment, context, predictedReview and predictedScore, plus top-level datasetId/model/task/deidentified=true/sourceApproved=true. Include the saved rubric in context; review all material for private data before distribution.
2. Run `python ops/review_jev_cases.py prepare predictions.json --output-dir new-packets`. Give review-a.json and review-b.json to two independent authorized staff through your approved channel. This task does not send files/messages to anyone.
3. Staff open Dashboard → Evaluation review, load their blind packet, label every case and export. Keep predictions hidden. The lead verifies reviewer identity and independent completion; no impersonation-proof signing is provided by this local packet workflow.
4. Run `python ops/review_jev_cases.py assemble predictions.json --review-a a.json --review-b b.json --output-dir new-assembly`. If disagreements exist, give the generated packet to a third reviewer, add a written reason per disputed label, then rerun with `--adjudication resolved.json` and a NEW output folder.
5. Run `python ops/evaluate_jev.py new-assembly/paired-cases.json --review-manifest new-assembly/review-manifest.json --model PINNED_MODEL --dataset-id DATASET_ID --task bulk_ats_semantics_v1 --output new-evaluation.json`. Practice uses `--task practice_rubric_feedback_v1` and separate data, with track:difficulty segments in lowercase. An artifact without reviewed provenance is diagnostic only and cannot enable rollout.
6. Review all labelled disagreements/errors and uncertainty intervals. Pin reviewed artifact SHA256, model and task-specific path. ATS settings remain JEV_BULK_ATS_*. Practice settings are JEV_PRACTICE_EVALUATION_PATH, JEV_PRACTICE_EVALUATION_SHA256, JEV_PRACTICE_ROLLOUT_PERCENT and bounded JEV_PRACTICE_TIMEOUT_SECONDS. Percent defaults 0. Restart API/worker to change environment settings. A model/rubric/task change requires new evaluated evidence.
