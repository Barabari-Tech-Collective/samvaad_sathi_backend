## Limits and unknowns

Zero cheating from an unseen second device cannot be guaranteed by a remote web app. Ship proportionate evidence and human verification rather than an unsupported guarantee. Jev replacement must be evaluated task by task; it is not an unconditional swap for all narrative generation. Embedded media, advanced panels/coding/whiteboards or a new infrastructure migration can exceed these ranges and require explicit rescoping.

Confidence is moderate for remaining ordinary code/UI work, lower for real-device/media, calibrated model quality and authenticated source integration until acceptance runs. New blockers change the range; document them. Production activation is currently held, not silently implied by successful local tests or pushes.
